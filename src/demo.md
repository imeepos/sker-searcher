# 核心需求

## StreamMarker Pro - 主播直播打点标注工具

专为主播设计的直播打点标注工具，通过快捷键快速标记直播精彩瞬间，提升后期剪辑效率。

### 核心功能

- **快捷键打点**：自定义快捷键快速标记精彩片段
- **时间轴标注**：自动记录打点时间轴，方便后期剪辑
- **多平台兼容**：支持主流直播平台和录屏软件
- **云同步**：打点数据可同步至云端，多设备共享
- **导出功能**：支持导出为剪辑软件兼容格式

### 适用场景

- 游戏主播标记精彩操作
- 才艺主播记录高光时刻
- 电商直播标记重点商品讲解
- 教育直播标注知识点
